## Watson 1.4.0

**Free. No account. One file.**

Bug fixes, a cleaner interface, and five new sources. The search flow is the same: one field, one answer.

### How to start

1. Download **Watson-1.4.0-portable.exe** — from [watsonfind.icu](https://watsonfind.icu) or from the asset below. Both are the same build.
2. Double-click it. If Windows shows a blue warning, click **More info**, then **Run anyway**.
3. Type a nickname, email, phone or website and press **Enter**.

Step-by-step pictures are in the [README](https://github.com/vaishantsah/watson-AI-osint-all-in-one#install-in-2-minutes). Website: [watsonfind.icu](https://watsonfind.icu).

### What's new

- **Fixes** — results no longer collapse when two profiles share an avatar, history keeps the newest search, long nicknames fit, the progress bar stops hanging at 98%, and the blank-window case after the Windows warning is gone.
- **Design** — new icon that stays readable at 16 px, taller search field, consistent cards, AA contrast in dark mode.
- **New tools** — Subfinder, crt.sh, GLEIF, Wayback Machine, GitHub Code Search (beta).

Full list: [CHANGELOG.md](https://github.com/vaishantsah/watson-AI-osint-all-in-one/blob/main/CHANGELOG.md).
